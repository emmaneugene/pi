# Before / After Examples

Worked examples for each rule. The point is to show the _kind_ of cut, not to memorize phrasings.

## Rule 1 — Cut significance inflation

**Before:** It's important to note that the migration plays a crucial role in improving system reliability.
**After:** The migration improves system reliability.

**Before:** In today's fast-paced business environment, communication is key.
**After:** Clear communication matters.

## Rule 2 — Use plain verbs

**Before:** We will utilize the new framework to facilitate faster onboarding and demonstrate value.
**After:** We'll use the new framework to speed up onboarding and show value.

## Rule 3 — End the sentence at the fact

**Before:** Wrap the object in `useMemo`, which allows React to reuse the same reference across renders, thereby preventing unnecessary re-renders.
**After:** Wrap the object in `useMemo` so React reuses across renders.

**Before:** Set the timeout to 30 seconds, ensuring that slow requests don't hang the client.
**After:** Set timeout to 30 seconds so slow requests don't hang the client.

## Rule 4 — Kill nominalizations

**Before:** The team will make a decision after giving consideration to the budget.
**After:** The team will decide after considering the budget.

**Before:** There was a failure of the service during deployment.
**After:** The service failed during deployment.

## Rule 5 — Earn every adjective and adverb

**Before:** This is a really very significant improvement that will truly help users substantially.
**After:** This improvement will help users. _(Quantify if you can: "cuts load time 40%.")_

## Rule 6 — Vary rhythm

**Before:** The API returns a token. The token expires in one hour. You refresh the token with the refresh endpoint. The refresh endpoint requires the old token.
**After:** The API returns a token that expires in one hour. To refresh it, call the refresh endpoint with the old token.

## Rule 7 — One idea per sentence

**Before:** We rebuilt the pipeline and it now runs nightly which means data is fresher and so dashboards load current numbers thereby reducing manual checks.
**After:** We rebuilt the pipeline to run nightly. Data is now fresher, so dashboards show current numbers and need fewer manual checks.

## Full passage

**Before (78 words):**

> It's worth mentioning that our comprehensive, cutting-edge solution leverages a robust set of features in order to empower users to seamlessly streamline their workflows. At the end of the day, this plays a crucial role in driving significant value, and it's important to note that early adopters have demonstrated a really substantial increase in productivity across the board.

**After (28 words):**

> Our tool helps users streamline their workflows. Early adopters increased productivity — one team cut report prep from three hours to forty minutes. _(Replace the vague "substantial increase" with the real number when you have it.)_
