# Writing Guidelines

Read `guidelines.md` (in this skill's directory) for the full rule set. Two modes:

## Authoring mode

When writing a durable prose artifact:

1. Read `guidelines.md`
2. Identify the medium and apply its register (see "Register by medium")
3. Write with the core principles and the exemplar voice for the genre
4. The mechanical rules are the floor, not the goal; the exemplar voice is the goal

## Review mode

When asked to review or refine existing prose:

1. Read `guidelines.md`
2. Read the specified files (or ask which files to review)
3. Check against core principles first, then mechanical rules
4. Output findings in the terse `file:line` format specified in the guidelines

## Chat responses

Conversational messages follow the core principles and voice & tone rules (lead with the answer, signal density, no AI tells, honest and direct). Artifact mechanics (TL;DR openers, heading and structure rules, placeholders) apply only to durable artifacts.
